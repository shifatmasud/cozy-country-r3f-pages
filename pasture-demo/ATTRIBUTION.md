# Asset provenance

The project models and texture images are extracted from the user-provided Cozy Country Android package (v2.6.5; package entry labeled modified by APKAward). They are not original assets created for this repository. See `public/assets/scene-assets.json` for the exact source names, Unity path IDs, source asset file, extracted paths and included scene paths.

No ownership or redistribution permission is claimed. Keep the repository private unless the game publisher's terms or written permission allow public redistribution.
