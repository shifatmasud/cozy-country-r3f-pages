# Asset provenance

The scene meshes and texture images are extracted from the user-provided Cozy Country Android package (v2.6.5; the package entry was labeled as modified by APKAward). They are not original assets created for this repository. See `public/assets/scene-assets.json` for the source Unity object names, path IDs, source asset file, extracted paths, and scene paths.

No ownership or redistribution permission is claimed. The APK itself is not included. Keep the source assets' provenance in mind when reusing the bundle; no license for redistribution was verified for this task.
